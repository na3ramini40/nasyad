# Nasyad 1.4.0

Clearer maintenance handoff, richer device tracking, and safer multi-device sync — still local-first. Install over your current version; your on-device data stays put.

## Client

- Share a device’s maintenance history as a PDF (device + nested parts) via the OS share sheet; plain-text clipboard fallback when share isn’t available (separate from Transfer backup).
- Confirming maintenance records the current usage reading and resets that node only; usage-based schedules show remaining and target.
- Tags for labeling devices; Home can group reminders by tag.
- When signed in with sync on, tags (and device–tag links) and map places sync across devices; a fresh second install pulls the account catalog instead of wiping remote tags/links.
- Two-finger pinch or Preferences slider scales the whole UI; color-blind theme keeps due/soon/OK status readable without red vs green.
- Android release APKs are split per CPU architecture (smaller downloads); in-app updates select the matching ABI.

## Server

- Tag and device–tag link APIs; tags participate in authenticated sync with devices, logs, birthdays, and places.
- Places sync (LWW) so map pins appear on a second signed-in device (photos stay local-only).
- Creating a device log on the server applies the same usage/maintenance side effects as the client model.
- OpenAPI `VERSION` bumped to 1.4.0 to match the coupled client tag.

## Install

Android APKs (per ABI), Linux `.tar.gz`, and Windows `.zip` are attached to this release. Prefer installing over a previous **release-signed** build so updates keep your local data.
