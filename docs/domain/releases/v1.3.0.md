# Nasyad 1.3.0

Optional online account and a richer local app — still local-first. Install over your current version; your on-device data stays put.

## Client

- Optional phone account — sign in with a one-time code, or keep using the app fully offline.
- Profile tab — view and edit your name and photo when signed in; sign out in one tap.
- App lock — protect the app with a password, PIN, or fingerprint; unlock after idle; reset lock with phone OTP if you forget.
- Check for app updates from GitHub — banner on Home or manual check in Preferences.
- Season themes (spring, summer, autumn, winter) with matching light and dark accents.
- Deep links (`nasyad://…`) open devices, birthdays, preferences, and more.
- Local due reminders — notify when maintenance is due or a birthday is coming up.
- Browse archived devices and restore whole subtrees.
- Mark maintenance done from a Home device reminder without opening the device first.
- Search devices, birthdays, and places by name from Home or Device management.
- Save places on a map (point, path, or area) and open them from Home.
- Optional category, location, and notes when editing a device.
- Bundled schedule templates (e.g. oil change, HVAC filter) when adding or editing a device.
- Maintenance logs can include optional cost, vendor, and a photo.
- Snooze Home reminders for 1, 3, or 7 days; set how many days count as “Soon” in Preferences.
- Export and import carry device metadata, log extras, photos, and places (JSON, CSV, plain text).

## Server

- New Django REST backend for optional sync and account features (self-host friendly).
- Phone OTP sign-in and profile APIs (`/api/accounts/`).
- Sync APIs for devices, device logs, and birthdays (authenticated; your rows only).
- Remote feature flags via `GET /api/app_config/` (gradual rollout / kill switch).
- Health check at `/api/health/`; OpenAPI docs when `DJANGO_DEBUG` is on.
- Single monorepo `.env/` folder for local/dev wiring (API URL, modes, signing, Django secrets); forks use `env.example/` placeholders.

## Install

Android APK, Linux `.tar.gz`, and Windows `.zip` are attached to this release. Prefer installing over a previous **release-signed** build so updates keep your local data.
