# l10n (en / fa)

All user-facing strings live in ARB files — never hard-code English or Persian in widgets.

## Files

- `lib/l10n/app_en.arb` — English source
- `lib/l10n/app_fa.arb` — Persian translations
- Generated: `lib/l10n/app_localizations.dart`

## Usage

```dart
final l10n = AppLocalizations.of(context)!;
Text(l10n.someKey);
```

Add keys to **both** ARB files in the same change. Run codegen if needed:

```bash
flutter gen-l10n
```

## Locales

- English (`en`) and Persian (`fa`, RTL).
- Switch via `LocaleCubit` on Preferences — not in feature code ad hoc.

## UX phase deliverable

## Changelog

Release notes also need en + fa — see `/bump-release` and `ChangelogEntry` in `app_changelog.dart`.

## Gates

- No user-visible literal strings in `presentation/` or `core/ui/`.
- RTL: avoid hard-coded `EdgeInsets.only(left: …)` when direction matters — use `Directionality` / symmetric padding.
