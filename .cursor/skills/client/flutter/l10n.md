# l10n & calendar

## Strings

- Source: `lib/l10n/app_en.arb` + `app_fa.arb` — add keys to **both** in the same change; `flutter gen-l10n` if needed.
- Usage: `AppLocalizations.of(context)!.someKey` — never literal user-facing text in `presentation/` or `core/ui/`.
- Locale switch: `LocaleCubit` on Preferences. `fa` is RTL — see ui.md.
- Release notes also need en + fa (`ChangelogEntry` — shared release rule).

## Calendar (independent of language)

- Preference: `CalendarSystemCubit` + store in `lib/core/calendar/` (`shared_preferences`).
- Conversion: `shamsi_date`; pickers like `MonthDayPickerField` in `lib/core/ui/`.
- Picker/display labels follow the **calendar preference**, not the locale.
- Birthdays: name + month/day, no year required; stored with per-row calendar system.
